## Scope and safeguards

With explicit user approval, a random temporary Function was added to the
existing `media-center` project. The project was **not paused**. No database,
schema, existing Function, application secret or project configuration was
read or changed by the probe. It never forwarded a request to an upstream.

The handler used an independently generated 256-bit token, accepted GET with no
body, and returned only its URL observation for the runner's fixed synthetic
case IDs. A SHA-256 digest, not the raw token, was embedded in its temporary
bundle. Authentication and a 30-minute hard expiry replaced platform JWT
verification for this diagnostic only. The token was kept in a user-restricted
temporary file; it was not put in arguments, logs, Git or the result report.
The handler performed no storage or logging and returned `Cache-Control:
no-store`. These safeguards do not assert that provider-internal logs are empty.

## Implementation and local verification

The recorded pairs first produced seven failing core tests. The fix compares
the path and query using only the known bytewise normalization forms, then
returns the original bound bytes. It never forwards a form-reserialized query
in place of the original. See the [binding contract](../supabase-path-binding.md).

Local verification passed:

- Core: **82 tests**, including all 16 observations and negative tampering cases.
- Supabase Deno: **36 Control + 67 Gateway tests**. Each recorded pair passes
  through the actual Gateway handler with a synthetic database/upstream, checks
  exact upstream URL spelling and signed target classification, then waits for
  report finalization. Unknown query rewrites are signed denials before quota
  or upstream work.
- The shared HTTP smoke test now simulates query form reserialization as well
  as slash/escape changes. Sensitive-query audit/report canaries include the
  `%20` to `+` ingress transformation.
- Diagnostic handler: **2 tests** covering fixed cases, authentication, expiry,
  response fields and rejection of unsupported requests.
